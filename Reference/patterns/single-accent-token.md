# 액센트 하나, 토큰 4개

**무엇** - 팔레트 전체를 변수 4개로 끝낸다. 액센트는 하나만.

```css
:root{
  --ink:   #11110f;   /* 텍스트 + 반전 배경 */
  --paper: #e9e6df;   /* 기본 배경 */
  --acid:  #d6ff43;   /* 유일한 액센트 */
  --line:  #11110f2e; /* ink의 알파 버전. 유일한 구분선 */
}
```

**왜 먹히나**
- 색이 적으면 실수할 데가 없다. 액센트가 하나면 그게 나올 때마다 의미가 생긴다
- `--line`을 별도 회색이 아니라 `--ink`의 알파로 잡으면 배경이 뭐든 자연스럽게 앉는다
- 토큰 4개면 리스킨이 4줄이다 ([theme-token-block.md](theme-token-block.md))

**액센트 쓰는 자리** - 호버 상태, 링크 밑줄, 아주 작은 도트/인디케이터, 반전 섹션의 kicker 텍스트. 넓은 면적에는 쓰지 않는다.

**중성 베이스 고르기** - 순수 `#000`/`#fff` 대신 살짝 온도를 준다. `#11110f`(웜 블랙), `#e9e6df`(페이퍼), `#050505`/`#f4f4f4`(뉴트럴). 순수 흑백은 화면에서 딱딱하다.

**calm 변형** - `--acid`를 채도 높은 색 대신 `--ink` 자기 자신으로 둔다. 그럼 액센트가 "색"이 아니라 "반전"이 된다. 흑백만 쓰는 사이트에서 위계를 만드는 방법.

```css
:root{ --ink:#111; --paper:#fafafa; --acid:#111; --line:#1111111f }
.link:hover{ background:var(--acid); color:var(--paper) }  /* 색 없이 강조 */
```
